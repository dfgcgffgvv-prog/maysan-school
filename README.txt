مشروع أولي لبوابة إعدادية ميسان للبنين

طريقة المعاينة:
- افتح index.html في المتصفح، أو ارفع محتويات المجلد إلى مستودع GitHub.
- بعد ذلك يمكن ربط المستودع بـ Cloudflare Pages.

مهم جداً:
هذه نسخة واجهة أولية وتجريبية وليست نظاماً مدرسياً جاهزاً للإنتاج.
- تسجيل الطالب في هذه النسخة تجريبي ويخزن البيانات في المتصفح (localStorage) فقط.
- لا تستخدم كلمات مرور حقيقية أو بيانات طلاب حقيقية في هذه النسخة.
- تسجيل المدرسين، التحقق بالبريد، الدردشة المباشرة، الإشعارات، والصلاحيات تحتاج خادماً وقاعدة بيانات ومصادقة آمنة.
- الجدول والامتحانات حالياً بيانات توضيحية فارغة.
- لم يتم استيراد صفحات SITE123 تلقائياً؛ هذه إعادة بناء أولية مبنية على المعلومات والصورة المتاحة.
